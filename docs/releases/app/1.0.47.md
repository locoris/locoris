# Locoris 1.0.47

## Summary

Local-first Locoris application release for Apple Silicon macOS, Windows x64, and Android.

## Security

Release artifacts are published from the protected GitHub Actions workflow. Android is signed with the stable Locoris release certificate; desktop updater artifacts use the Locoris updater signature.

## Added

- Production-oriented cloud and self-hosted connection flows.

## Improved

- Mobile planner, calendar, map controls, synchronization recovery, themes, backups, and product onboarding.

## Fixed

- Multiple mobile viewport, authentication refresh, Google Drive reauthorization, and synchronization feedback issues.

## Compatibility

- macOS: Apple Silicon only.
- Windows: Windows 10/11 x64.
- Android: direct signed APK.
- Locoris Server: sync protocol version 1.

## Migration

No manual local-vault migration is required. Keep a current backup before updating.

## Update

Install the new build over the existing application or use the desktop updater when offered.

## Rollback

Restore the previous installer and a backup made before the update if a data migration prevents normal use.

## Known issues

macOS and Windows direct builds are not yet backed by paid platform certificates, so the operating system can show an unknown-developer warning.

## Verification

Compare the downloaded artifact against `SHA256SUMS.txt` and verify its GitHub artifact attestation before bypassing an operating-system warning.
