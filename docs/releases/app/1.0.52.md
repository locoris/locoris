# Locoris 1.0.52

## Summary

Google Drive performance and reliability release for Apple Silicon macOS, Windows x64, Android, and the hosted web application.

## Security

Private-vault checkpoints and change batches remain encrypted on the client before they reach Google Drive. Conflict detection and immutable commit retention remain enabled while network traffic is reduced.

## Added

- Indexed Google Drive checkpoint metadata for lightweight revision and payload-mode checks.
- Regression coverage for manifest catalog loading, concurrent catalog requests, token probes, selective checkpoint reads, and unapplied commits.

## Improved

- Opening Google Drive sync now reads the manifest catalog instead of rebuilding every remote vault from its complete history.
- Normal synchronization downloads one selected checkpoint and only commits that have not yet been applied.
- Unchanged vaults use lightweight revision checks and no longer transfer a complete snapshot.
- The compatibility mirror is copied inside Google Drive, so a complete snapshot is uploaded from the device only once.

## Fixed

- Google Drive connections no longer remain indefinitely in the checking state after a failed catalog request.
- Applied historical commits and inactive retained checkpoints are no longer repeatedly downloaded during every sync cycle.
- Empty merge cycles no longer upload an identical snapshot again.
- Concurrent catalog opens share one request instead of duplicating the same network work.

## Compatibility

- macOS: Apple Silicon only.
- Windows: Windows 10/11 x64.
- Android: direct APK signed by the stable Locoris release certificate.
- Google Drive: existing manifest, legacy mirror, and v2 checkpoint data remain readable.
- Locoris Server: sync protocol version 1.
- Locoris Cloud: 0.1.4 recommended.

## Migration

No local-vault migration or Google Drive reconnection is required. The first sync of an older Google Drive vault may perform one compatibility read before later cycles use the indexed path.

## Update

Install the new build over the existing application or accept the signed desktop updater when offered. Android updates require the existing installation to use the same Locoris signing certificate.

## Rollback

Reinstall the previous verified artifact. Local vaults and existing remote Google Drive files remain compatible and do not require a rollback migration.

## Known issues

The first transfer of a very large vault still depends on the available Google Drive bandwidth. macOS and Windows builds are not yet backed by paid platform certificates, so Gatekeeper and SmartScreen can show an unknown-developer warning.

## Verification

Compare the complete SHA-256 digest with `SHA256SUMS.txt`, then run `gh attestation verify <file> --repo locoris/locoris`. Android users can additionally compare the published signing-certificate fingerprint.
