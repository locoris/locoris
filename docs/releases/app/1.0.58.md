# Locoris 1.0.58

## Summary

Mobile note editor interaction release for the hosted web application, installed iOS Web App, Android, macOS, and Windows.

## Security

This release does not change vault encryption, synchronization encryption, account authentication, credential storage, or exported data formats.

## Added

- A portrait-first mobile note editor shell with dedicated header, selection toolbar, keyboard accessory bar, format sheet, and insert sheet.
- Persistent formatting-selection handling so multiple style changes can be applied without losing the selected text.
- Regression coverage for mobile press behavior, visual-viewport handling, and rich-text format selection.

## Improved

- Mobile editor actions and nested formatting controls now use a consistent single-tap interaction contract.
- The format sheet opens from the bottom edge, replaces the underlying editor bar, and keeps the edited selection visible above it.
- Font, block type, alignment, inline style, and color controls reflect the actual formatting of the current selection.
- Keyboard and visual-viewport changes no longer leave unnecessary space below the editor or move controls outside the usable area.

## Fixed

- Font choices other than Unbounded now apply to the active text selection.
- Changing one style no longer clears the selection or prevents subsequent changes in the same sheet.
- Closing the format sheet restores normal cursor placement, text selection, scrolling, and keyboard interaction.
- Selection actions, dropdowns, reading mode, navigation, and AI controls no longer require repeated taps on mobile web.

## Compatibility

- macOS: Apple Silicon only.
- Windows: Windows 10/11 x64.
- Android: direct APK signed by the stable Locoris release certificate.
- Hosted web application and installed iOS Web App: updated by the web deployment.
- Locoris Server: sync protocol version 1.
- Locoris Cloud: 0.1.4 or newer recommended.

## Migration

No vault-data migration is required. Existing notes, local vaults, Cloud bindings, sessions, and synchronization methods remain compatible.

## Update

Install the new build over the existing desktop or Android application. The hosted web application updates automatically; fully close and reopen an installed iOS Web App once if Safari keeps an older cached shell.

## Rollback

Reinstall the verified 1.0.57 artifact. Vault data remains compatible, but the previous mobile editor selection, formatting-sheet, and single-tap behavior will return.

## Known issues

macOS and Windows builds are not yet backed by paid platform certificates, so Gatekeeper and SmartScreen can show an unknown-developer warning. iOS controls native text-selection handles and the final software-keyboard animation; Locoris positions its own controls inside the resulting Visual Viewport.

## Verification

Compare the complete SHA-256 digest with `SHA256SUMS.txt`, then run `gh attestation verify <file> --repo locoris/locoris`. Android users can additionally compare the published signing-certificate fingerprint.
