# Locoris 1.0.55

## Summary

Mobile editing and Account/Cloud experience release for web, iOS Web App, Android, macOS, and Windows.

## Security

Locoris continues to renew hosted Cloud sessions through the same-origin HttpOnly browser session on web and the application-owned private credential store on native platforms. This release does not change vault encryption, sync encryption, or exported data formats.

## Added

- A dedicated mobile editor toolbar with touch-safe paragraph, heading, list, checklist, style, and insertion actions.
- Visual Viewport handling for iOS Safari and installed Web Apps so the note editor follows the visible screen while the software keyboard is open.
- A compact Account/Cloud identity surface that keeps profile, subscription, quota, refresh, and sign-out state together across desktop and portrait layouts.

## Improved

- The Account/Cloud workspace now keeps its primary tabs stable while presenting vault and device management in a denser, scrollable layout.
- Hosted Cloud connections use the product Cloud endpoint by default instead of exposing server configuration in the customer sign-in flow.
- The mobile note editor keeps the active caret, formatting controls, link tools, file tools, and AI panel inside the keyboard-safe viewport.
- AI opens its panel before preparing a whole-note context, providing immediate feedback even for large documents.
- Mobile tables support independent horizontal and vertical panning without triggering an accidental editor focus change.

## Fixed

- Tapping text or empty editor space on mobile now reliably focuses the document and opens the keyboard without breaking scroll gestures.
- Quick formatting actions restore editor focus and apply on the first deliberate tap.
- Selection and contextual editor controls no longer appear underneath the iOS keyboard.
- Long Account/Cloud vault lists can be reached without profile content or nested navigation consuming the usable viewport.
- Account identity content no longer disappears or shifts the tab position when switching between vaults and devices.

## Compatibility

- macOS: Apple Silicon only.
- Windows: Windows 10/11 x64.
- Android: direct APK signed by the stable Locoris release certificate.
- Hosted web application and installed iOS Web App: updated by the web deployment.
- Locoris Server: sync protocol version 1.
- Locoris Cloud: 0.1.4 or newer recommended.

## Migration

No vault-data migration is required. Existing local vaults, Cloud bindings, account sessions, editor documents, and synchronization methods remain compatible.

## Update

Install the new build over the existing desktop or Android application. The hosted web application updates automatically; fully close and reopen an installed iOS Web App once if Safari keeps an older cached shell.

## Rollback

Reinstall the verified 1.0.54 artifact. Vault data and Cloud bindings remain compatible, but the previous mobile editor and Account/Cloud interface behavior will return.

## Known issues

macOS and Windows builds are not yet backed by paid platform certificates, so Gatekeeper and SmartScreen can show an unknown-developer warning. iOS controls the final software-keyboard animation and native text-selection handles; Locoris keeps its own controls within the resulting Visual Viewport.

## Verification

Compare the complete SHA-256 digest with `SHA256SUMS.txt`, then run `gh attestation verify <file> --repo locoris/locoris`. Android users can additionally compare the published signing-certificate fingerprint.
