# Locoris 1.0.48

## Summary

Reliability release for Apple Silicon macOS, Windows x64, and Android with an atomic, independently verifiable distribution pipeline.

## Security

Every public artifact is staged in a hidden draft, hashed in a unified checksum file, described by an SPDX SBOM, and bound to the protected Locoris workflow with GitHub artifact attestations. The Android APK must match the pinned Locoris signing certificate before publication.

## Added

- Unified `SHA256SUMS.txt`, SPDX SBOM, Android certificate metadata, and GitHub artifact attestations.
- Versioned release notes with explicit compatibility, migration, rollback, and verification guidance.

## Improved

- A release remains private until macOS, Windows, Android, updater metadata, checksums, and attestations all pass.
- macOS distribution is explicitly limited to Apple Silicon and uses a verified ad-hoc signature while notarization is unavailable.

## Fixed

- Partial releases can no longer become public when one required platform fails.
- Android publication now rejects an APK signed by an unexpected certificate.

## Compatibility

- macOS: Apple Silicon only.
- Windows: Windows 10/11 x64.
- Android: direct APK signed by the stable Locoris release certificate.
- Locoris Server: sync protocol version 1.

## Migration

No local-vault migration is required. Create a current backup before updating as normal.

## Update

Install the new build over the existing application or accept the signed desktop updater when offered. Android updates require the existing installation to use the same Locoris signing certificate.

## Rollback

Reinstall the previous verified artifact. Restore a pre-update backup only if application data cannot be opened normally after downgrading.

## Known issues

macOS and Windows builds are not yet backed by paid platform certificates. Gatekeeper and SmartScreen can therefore show an unknown-developer warning; follow the official direct-install guide after verifying the artifact.

## Verification

Compare the complete SHA-256 digest with `SHA256SUMS.txt`, then run `gh attestation verify <file> --repo locoris/locoris`. Android users can additionally compare the published signing-certificate fingerprint.
