# Locoris 1.0.59

## Summary

Clear Cloud subscription status, expiry dates, and renewal information across web, macOS, Windows, and Android.

## Security

Cloud write access continues to be enforced by the server. This release preserves authentication, device credentials, encryption, and vault bindings.

## Added

- An explicit expired-plan status with the date and reason sync writes are paused.
- Renewal information that distinguishes manual renewal without charges, expiry, and access without a time limit.
- A Cloud recovery action in account settings.
- Regression coverage for expired, blocked, refunded, grace, and unlimited access presentation.

## Improved

- The account popover and account settings share the same access-state presentation.
- Cloud access refreshes each minute while visible and when returning to the foreground on web and native platforms.
- Restored write access schedules synchronization for the current Cloud vault without signing in again.
- Russian, English, and all other supported locale catalogs include the new status and renewal messages.

## Fixed

- Expired manual access no longer appears as an active unlimited plan without an explanation.
- Access without an expiry no longer reuses a previous trial's expired date.
- Blocked, refunded, and grace states remain distinct from expiry.
- The account popover avoids repeating the same expiry notice twice.

## Compatibility

- macOS: Apple Silicon.
- Windows: Windows 10/11 x64.
- Android: APK signed by the stable Locoris release certificate.
- Hosted web and installed iOS Web App: updated through the web deployment.
- Locoris Cloud 0.1.6 supplies the complete effective-status and manual-renewal contract; older Cloud responses remain readable.
- Locoris Server: sync protocol version 1.

## Migration

No client vault-data migration is required. Existing notes, local vaults, sessions, sync methods, and credentials remain compatible. Installing this update does not extend or revoke any account's Cloud access.

## Update

Install over the existing desktop or Android application. Reload the hosted web application; close and reopen an installed Web App if it retains a cached shell.

## Rollback

Reinstall the verified 1.0.58 artifact. Vault data remains compatible; the previous Cloud status presentation and refresh behavior return.

## Known issues

macOS and Windows builds do not use paid platform certificates, so the operating system may show an unknown-developer warning. Manual access renewal grants access without charging a payment method.

## Verification

Compare artifacts against SHA256SUMS.txt and verify their GitHub attestations with `gh attestation verify <file> --repo locoris/locoris`. Compare Android's published signing-certificate fingerprint when updating manually.
