# Locoris 1.0.56

## Summary

Mobile note editor interaction release for the hosted web application, installed iOS Web App, Android, macOS, and Windows.

## Security

This release does not change vault encryption, synchronization encryption, account authentication, credential storage, or exported data formats.

## Added

- Regression coverage for mobile selection-toolbar placement above, below, and within constrained editor viewports.

## Improved

- The mobile editor now gives native iOS text placement priority, making a single tap the primary interaction for text, empty document space, and editing controls.
- Manual document scrolling temporarily suspends caret correction so readers can inspect content away from the active insertion point.
- The selection toolbar chooses the available side of highlighted text and remains inside the keyboard-safe editor viewport.

## Fixed

- Text placement and mobile editor actions no longer require a second tap.
- Scrolling away from the active caret no longer snaps the document back to the insertion point.
- The contextual formatting toolbar no longer opens directly over the highlighted text when usable space is available above or below it.
- Touch formatting actions preserve the current editor selection while firing only once.

## Compatibility

- macOS: Apple Silicon only.
- Windows: Windows 10/11 x64.
- Android: direct APK signed by the stable Locoris release certificate.
- Hosted web application and installed iOS Web App: updated by the web deployment.
- Locoris Server: sync protocol version 1.
- Locoris Cloud: 0.1.4 or newer recommended.

## Migration

No vault-data migration is required. Existing notes, local vaults, Cloud bindings, sessions, and synchronization methods remain compatible.

## Update

Install the new build over the existing desktop or Android application. The hosted web application updates automatically; fully close and reopen an installed iOS Web App once if Safari keeps an older cached shell.

## Rollback

Reinstall the verified 1.0.55 artifact. Vault data remains compatible, but the previous mobile editor tap, scrolling, and selection-toolbar behavior will return.

## Known issues

macOS and Windows builds are not yet backed by paid platform certificates, so Gatekeeper and SmartScreen can show an unknown-developer warning. iOS controls the final software-keyboard animation and native text-selection handles; Locoris positions its own controls within the resulting Visual Viewport.

## Verification

Compare the complete SHA-256 digest with `SHA256SUMS.txt`, then run `gh attestation verify <file> --repo locoris/locoris`. Android users can additionally compare the published signing-certificate fingerprint.
