# Locoris Server 0.1.4

## Summary

Self-hosted Locoris synchronization with SQLite metadata, portable vault files, Docker, and desktop packages.

## Security

Device-scoped credentials, one-time pairing invitations, encrypted-vault ciphertext storage, and hashed server tokens remain the supported access model.

## Added

- SQLite metadata backend and separate portable vault files.
- Desktop and Docker installation paths.

## Improved

- Pairing, device management, endpoint recovery, backups, and fixed-port diagnostics.

## Fixed

- Persistence and token continuity across normal server restarts.

## Compatibility

- Sync protocol 1, API contract 1, pairing protocol 1, storage schema 2.
- Desktop server: Apple Silicon macOS, Windows x64, and Linux x64.
- Docker: Linux amd64 and arm64 from releases built after the new distribution workflow is enabled.

## Migration

Legacy JSON metadata is imported once into SQLite and archived under `legacy-json/`. Vault payload files stay in place.

## Update

Back up the complete data directory. Desktop users install the new package over the current version; Docker users pull the numbered image and recreate the service.

## Rollback

Stop the server and restore the complete pre-update data-volume backup together with the previous binary or image. Never mix SQLite files and `vaults/` from different backups.

## Known issues

macOS and Windows desktop packages are not yet backed by paid platform certificates. The operating system can show an unknown-developer warning.

## Verification

Compare packages with the published `SHA256SUMS.txt`. Future releases produced by the hardened workflow also expose GitHub attestations and signed container manifests.
